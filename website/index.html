YouTube-SuperUploaderMCP

YouTube-SuperUploaderMCP is a private tool that uploads videos to YouTube channels owned and managed by S M Abdul Mueid, using the official YouTube Data API v3. It is not a public service and has no other users.

What it does

  • Uploads Shorts and long-form videos to 9 YouTube channels, one OAuth token per channel.
  • Sets titles, descriptions, tags, and custom thumbnails.
  • Supports scheduled publishing.
  • Keeps a separate upload log for each channel.

Permissions it requests

When a channel is connected, Google asks for these YouTube permissions:

  • youtube.upload — upload videos to the channel.
  • youtube — manage the YouTube account.
  • youtube.readonly — view the YouTube account.
  • yt-analytics.readonly — view YouTube Analytics reports.

Nothing else is requested. The app never changes channel permissions, never reads email, and never accesses any other Google service.

Privacy

OAuth tokens are stored securely on the owner's own machine and are never shared or sold. Full details are in the Privacy Policy.
